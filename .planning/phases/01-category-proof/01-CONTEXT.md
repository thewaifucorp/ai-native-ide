# Phase 1 Context: Category Proof

## Outcome

Prove one narrow but real desktop journey: a user describes a change to the leaderboard/auction benchmark, an interchangeable agent edits real files, a live preview reflects the result, the IDE exposes one scoped permission and one intent↔implementation divergence, and Game Mode progresses only after verification.

## Locked decisions

- Vertical walking skeleton; never frontend-first or backend-first horizontal delivery.
- Compare Tauri and Electron using the same representative slice, then keep one.
- React/TypeScript UI, Rust-oriented privileged core boundary, Monaco candidate, real PTY.
- AAG is an external degradable graph/evidence provider, not the source of truth.
- Project is semantic and above repos/sessions; Phase 1 may use one benchmark repo while preserving the boundary.
- Hybrid, balanced permissions, reversible checkpoints, no paid idle inference.
- Instrument visual language and progressive depth from global `UI-SPEC.md`.
- Essential and Raw must both be reachable in the slice.
- Context Dock is canonical for permissions; Activity Strip links actions to observed effects.
- Authorization itself never grants Game Mode progression.
- No required Katsui, ShinAI infrastructure, marketplace, cloud account, or subscription.

## Benchmark

A small paid-placement leaderboard/auction product. Critical scenario: sealed bids and two concurrent bids must result in a single valid winner without revealing the current winning value. This exercises UI, state, concurrency, permissions, preview, evidence, and intent reconciliation.

## Required technical proofs

1. Desktop shell opens project and communicates through a typed privileged boundary.
2. Real file read/write and external-change observation.
3. Real PTY/process lifecycle with streaming, cancellation, and cleanup.
4. Preview starts, reloads, fails, and reconnects without compromising the host.
5. One ACP path and one CLI/PTTY agent path are evaluated for auth, resume, cancel, capability, and degradation.
6. Reversible checkpoint surrounds one mutation.
7. AAG external provider can be present or absent without blocking the journey.
8. One deterministic check and one semantic divergence produce evidence honestly.
9. Same slice informs the Tauri/Electron decision with measured evidence.

## Scope fences

- No generalized marketplace or inference rail.
- No complete plugin system.
- No production-grade multi-repo semantic graph yet.
- No full Katsui Company Brain capabilities.
- No comprehensive harness packs.
- No polished publishing platform.
- No multiple companions, seasons, leaderboards, or cloud progression.

## Founder delegation

Remaining implementation-level choices may be decided by the team as long as they preserve the product thesis, Katsui boundary, free/local core, model neutrality, and simplified default UX.
