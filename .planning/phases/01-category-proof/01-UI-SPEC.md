# Phase 1 UI Contract: Category Proof

The global `.planning/UI-SPEC.md` is authoritative. This phase must implement the smallest representative Instrument slice:

- Project Rail with benchmark project.
- Navigator: Overview, Build, Resources, Evidence.
- Work Surface: intent/conversation, live preview, Monaco candidate, minimal diff.
- Context Dock: agent, resource scope, capability/effect summary, one canonical permission.
- Activity Strip: streaming activity and expandable action→effect→evidence timeline.
- Essential depth for outcome-oriented use and Raw depth for files/editor/terminal/evidence.
- Hybrid and balanced visible as defaults but not exposed as setup burden.
- One Game Mode outcome with receipt after effect completes and checks pass.

Instrument tokens: neutral graphite/white chrome; blue step, amber human action, green verified, red broken; Geologica + DM Mono locally bundled; compact IDE controls; reduced motion.

Acceptance: nontechnical user finds objective/result/decision in ten seconds; technical user reaches code/terminal/raw evidence within two actions; disabling Game Mode removes no functional capability.
