# Evidência de tela

Capturas das telas que provaram cada passo, na ordem em que aconteceram. Elas
estavam soltas na raiz do repositório sem ninguém decidir o que eram; ficam aqui
porque são **evidência**, não decoração: cada uma é o estado real do app rodando
no momento em que uma afirmação da fila passou a ser verdade.

| arquivo | o que prova |
|---|---|
| `sketch-001.png` … `sketch-003d.png` | esboços de direção da casca, antes de existir app |
| `spike-001.png` | o spike que decidiu o pivô para Theia |
| `theia-001-ia.png` | a arquitetura de informação do Theia com a casca aplicada |
| `theia-sqltools.png` | plugin de terceiro (SQLTools) rodando dentro do host |
| `m1-instrument-shell.png`, `m1-final.png` | casca M1 |
| `m2-final.png` | M2 |
| `m8-tools-capabilities.png` | plataforma de capabilities e harness na tela (§1) |
| `permission-card-pending.png` | o card de permissão do agente bloqueando o turno (§1e/§11) |

Regra para o que entra aqui: captura de app RODANDO. Mockup e render de
protótipo não entram — se entrarem, a pasta deixa de significar prova.
